# clampglob

Clamp timestamps and glob durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/clampglob/

## Install / run

```bash
git clone https://github.com/theworker02/clampglob.git
cd clampglob
node src/cli.js
node --test
```
